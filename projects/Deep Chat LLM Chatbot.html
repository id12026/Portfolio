Deep Chat: Customizable Chatbot with API & LLM Integration

  • Tech Stack: Python, Transformers, LangChain, Streamlit, LoRA, ChromaDB, Ollama, Tesseract OCR
  • Timeline: Jan 2025 – Apr 2025
  • Github URL: Project Link

Deployed an LLM-based chatbot using RAG (Retrieval-Augmented Generation) with fine-tuned models via LoRA and 4-bit quantization, reducing model size by 70% while maintaining performance benchmarks. This optimization enables efficient deployment on resource-constrained environments.

Optimized response latency by 30% using SentenceTransformers embeddings and ChromaDB vector store; integrated Tesseract OCR for querying PDFs and scanned documents. The system efficiently processes and retrieves relevant information from large document collections.

Built a dynamic LangChain pipeline with multi-format document interaction capabilities, improving user experience across text, PDF, and image inputs. The chatbot supports various document types and provides intelligent, context-aware responses.

The application leverages Ollama for local LLM deployment, ensuring data privacy while delivering powerful conversational AI capabilities. Users can interact with their documents through natural language queries, making information retrieval intuitive and efficient.
